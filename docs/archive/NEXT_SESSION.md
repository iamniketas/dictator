## ✅ Что уже реализовано (v0.2.3)

### Стриминг транскрипции
- ✅ Polling каждые 3/8/15 секунд (выбор в трее)
- ✅ Partial text отображается в overlay в реальном времени
- ✅ Final text передаётся после остановки записи
- ✅ Корректная очистка буфера между записями
- ✅ Неблокирующий UI при warmup Whisper

### Overlay UI
- ✅ Win32 окно с прозрачностью (layered)
- ✅ REC индикатор с пульсацией
- ✅ Двухзонный интерфейс: статус (верх) + текст (низ)
- ✅ Drag & drop для перемещения
- ✅ Позиционирование рядом с курсором
- ✅ Показ прогресса: секунды записи, ETA, статистика
- ✅ Почти непрозрачный фон с рамкой для читаемости

### Основной функционал
- ✅ Горячая клавиша Ctrl+Shift+D
- ✅ Запись аудио через cpal
- ✅ Транскрипция через Whisper
- ✅ LLM коррекция через Ollama
- ✅ Вставка текста в активное окно
- ✅ Управление Whisper сервером
- ✅ Встраиваемая иконка приложения
