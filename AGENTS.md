## О проекте

**Dictator** — приложение для диктовки текста с использованием локальных моделей:
- Запись аудио по горячей клавише (Ctrl+Shift+D)
- Расшифровка через локальный Whisper сервер
- **Два режима работы:**
  - **Стриминг** (0.1s) — быстро, для команд, через трей меню
  - **Полная транскрипция** (2.6s) — качественно, для документов
- Опциональная коррекция через Ollama
- Вставка текста в активное окно
- Overlay окно с прокруткой текста

## Архитектура

### Поток данных (стриминг)
```
Recording Thread (cpal)
    ↓
Audio Buffer (растёт)
    ↓
ChunkDetector (каждые 3 сек, polling)
    ↓
Whisper HTTP Request (в отдельном потоке)
    ↓
Partial Text → Overlay UI (последние 5 строк)
    ↓
При остановке: финальная обработка + Text Injection
```

### Поток данных (полная транскрипция)
```
Recording Thread (cpal)
    ↓
При остановке: полный буфер → Whisper
    ↓
Результат → Text Injection
```

## Лучшие практики (выявленные в работе)

### 1. Порядок операций при остановке записи
**Проблема:** Если остановить запись до стриминга, буфер очистится.
**Решение:** Сначала стоп стриминга (читает буфер), потом стоп записи.
```rust
// Правильно:
st.stop();  // Читает финальный буфер
recorder.stop_recording();  // Очищает буфер
```

### 2. Обратная совместимость конфига
Всегда используй `#[serde(default)]` для новых полей:
```rust
#[serde(default)]
pub enabled: bool,
```

### 3. Прокрутка текста в overlay
**Не работает:** `DT_BOTTOM` с `DT_WORDBREAK`
**Работает:** Ручное разбиение на строки + показ последних N:
```rust
fn get_last_lines(text: &str, max_lines: usize, max_chars: usize) -> String
```

### 4. Переключение режимов
Используй `AtomicBool` для thread-safe состояния:
```rust
static STREAMING_ENABLED: AtomicBool = AtomicBool::new(false);
```

### 5. Проверка перед коммитом
- `cargo check` — нет ошибок
- `cargo clippy` — нет warning'ов
- Тест на реальном сценарии
