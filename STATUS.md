## 📁 Структура проекта

```
src/
├── main.rs           # Точка входа, event loop
├── lib.rs            # Модульные экспорты
├── audio.rs          # Аудио запись (cpal)
├── streaming.rs      # Стриминг транскрипции
├── transcribe.rs     # Whisper HTTP клиент
├── llm.rs            # Ollama клиент
├── input.rs          # Hotkey + вставка текста
├── config.rs         # Конфигурация (TOML)
├── ui.rs             # Системный трей
├── overlay.rs        # ⚠️ Устарел (не используется)
└── overlay_win32.rs  # ✅ Активный overlay

examples/
├── test_overlay.rs   # ⚠️ Требует исправления API
└── async_test.rs     # ⚠️ Устарел
```

## 📊 Метрики

| Параметр | Значение |
|----------|----------|
| Время запуска | ~1-2 сек |
| Задержка стриминга | ~3 сек (по умолчанию) |

| Задержка LLM | ~1-3 сек |
| Размер бинарника | ~5 MB |

---

## 📝 Примечания

- Стриминг реализован через **синхронный polling** (не async) для простоты
- Overlay работает в **отдельном потоке** (winit event loop)
- Аудио конвертируется в 16kHz mono для Whisper
- Поддержка Windows только (Win32 API)
